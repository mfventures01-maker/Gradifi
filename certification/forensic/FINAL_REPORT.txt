[2] FINDING B CLASSIFICATION SUMMARY (DOCX REJECTION AT LINE 208)

  Classification: PKZIP LOCAL-HEADER PARSER DEFECT (STREAMING DATA DESCRIPTORS)
  Root Cause:     Custom byte scanner in `officeZipAdapter.ts` reads compressed &
                  uncompressed sizes from Local File Headers (bytes 18-25). For files
                  encoded with streaming Data Descriptors (`flags = 0x808`), these
                  header fields are 0 per PKZIP spec. `officeZipAdapter.ts` calculates
                  `payloadSize = 0`, corrupts archive traversal, fails to extract
                  `word/document.xml`, and triggers line 208 rejection: "The uploaded
                  file is not a valid DOCX package."
