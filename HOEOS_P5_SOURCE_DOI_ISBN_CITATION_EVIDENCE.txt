SOURCE IDENTITY
Primary join key between matched evidence spans and public source records is strictly sourceId.
No secondary text or title re-matching is performed. If sourceId is unavailable, a truthful unavailable state is presented.

DOI
Validated DOIs are displayed with navigable HTTPS links (https://doi.org/${cleanDoi}) only when valid and present in the authoritative public record.
Missing DOIs render truthful unavailable badge: "DOI unavailable". No DOIs are fabricated.

ISBN
Validated ISBNs (ISBN-10 or ISBN-13) are formatted cleanly and displayed only when supplied by the authoritative book source record.
Missing ISBNs render truthful unavailable badge: "ISBN unavailable". No ISBNs are fabricated.

CITATION
Generates deterministic multi-style academic citations (APA, MLA, Chicago, Harvard) using authoritative metadata fields provided by the public result contract.
Zero metadata field fabrication.

GOOGLE BOOKS BOUNDARY
Google Books sources are explicitly labeled "Book Source (Bibliographic)" and presented as bibliographic evidence only.
Never labeled as plagiarism authority or proof of plagiarism.

AI AUTHORITY BOUNDARY
AI interpretation outputs remain strictly labeled NON_AUTHORITATIVE_INTERPRETATION.
AI chatter cannot create or alter DOIs, ISBNs, sources, citations, or matched spans.

G3 BOUNDARY
P5 is a pure presentation layer. G3 remains sole authority for plagiarism classification and human-review policy.
P5 does not calculate, alter, or override G3 risk levels or similarity percentages.

DETERMINISM
Source ordering is deterministically sorted using sourceId ASC tie-breaker.
50 consecutive model generations produced identical presentation output.
Zero Math.random(), Date.now(), or random UUIDs used in formatting or citation logic.

SECURITY
All metadata (titles, authors, publishers, identifiers) render via safe React DOM text nodes.
HTML injection payloads (<script>alert("XSS")</script>, <img onerror=...>) render safely as literal text.
Zero secret leakage: API keys, service role credentials, bearer tokens, HTTP statuses, and provider logs are strictly excluded from public presentation.
