2. WHY THE FREEZE IS LIFTED
--------------------------------------------------------------------

The G5 deterministic engine already computes paragraph-level and
sentence-level evidence as part of every similarity run. That
evidence is captured in GlobalSimilarityAggregation at:

  deterministicEngine.ts:666-683

and returned by analyzeDocumentEvidence at:

  deterministicEngine.ts:700

The public wrapper evaluateDocumentSimilarity at line 710 already
receives that aggregation via engineOutput.aggregation, uses it to
build the returned findings at line 764, and then discards it when
composing its return object at lines 786-796.

The result: the aggregation exists. It is computed. It is available.
It is simply not surfaced.

The student-facing correction workflow requires the paragraph and
sentence evidence. There is no way to expose it from outside the
engine without either:

  (a) modifying deterministicEngine.ts to add a new internal
      function that returns the aggregation alongside the existing
      result, or

  (b) rebuilding the evidence pipeline outside the engine and
      fabricating a second engine invocation.

Option (b) was attempted. It was rejected because it required
constructing a synthetic EvidenceMatch with fabricated provenance
(provider: "openalex", provenanceState: "VERIFIED", a 1970 timestamp).
That is a contract violation, not an implementation shortcut.

Option (a) is the correct path. It is the amendment this document
records.

3. PERMITTED CHANGE
--------------------------------------------------------------------

The following change is authorized:

  Add a new exported function evaluateDocumentSimilarityInternal to
  src/services/verify/deterministicEngine.ts with the same signature
  as evaluateDocumentSimilarity:

    evaluateDocumentSimilarityInternal(
      sourceDoc: CanonicalAnalysisDocument,
      comparisonDoc: CanonicalAnalysisDocument
    ): GranularSimilarityResult

  where GranularSimilarityResult extends SimilarityAnalysisResult
  and adds two fields:

    paragraphFlags: ParagraphMatchEvidence[]
    sentenceFlags: SentenceMatchEvidence[]

  The function body must be identical to the current body of
  evaluateDocumentSimilarity, except that its return object must
  additionally include the two flag arrays copied from
  engineOutput.aggregation:

    paragraphFlags: engineOutput.aggregation.paragraphFlags
    sentenceFlags: engineOutput.aggregation.sentenceFlags

  evaluateDocumentSimilarity must then delegate to
  evaluateDocumentSimilarityInternal and return its result. Its
  declared return type remains SimilarityAnalysisResult for
  backward compatibility.

The change is ADDITIVE. It does not remove, rename, or alter any
existing exported function.

4. PROHIBITED CHANGES
--------------------------------------------------------------------

The following changes are forbidden in this migration:

  4.1  Changing the value of overallSimilarity
  4.2  Changing tokenization (tokenize)
  4.3  Changing overlap calculation (calculateNGramOverlap,
       calculateExactPhraseMatch, detectPhraseMatches)
  4.4  Changing source aggregation (aggregateSourceScore,
       deduplicateSources)
  4.5  Changing threshold logic (the 20% gate at line 517, the flag
       thresholds in evaluateSentenceMatch and evaluateParagraphMatch)
  4.6  Changing normalization (normalizeText, NORMALIZE_VERSION)
  4.7  Changing the semantics of any evidence field
  4.8  Introducing a second similarity algorithm
  4.9  Constructing a synthetic EvidenceMatch to feed
       analyzeDocumentEvidence a second time
  4.10 Setting provenance.provider to a value that is not the actual
       provider
  4.11 Setting provenance.provenanceState to VERIFIED when no
       verification occurred
  4.12 Setting provenance.retrievedAt to a fixed timestamp such as
       1970-01-01T00:00:00.000Z
  4.13 Touching any file outside the authorized scope below
