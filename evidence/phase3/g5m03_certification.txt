KNOWN GAPS NOT ADDRESSED BY G5-M03
--------------------------------------------------------------------

  GAP 1 - Production DOCX upload end-to-end is NOT tested.
    The extractor is certified against fixtures. The full path
    from browser upload UI through ingestDocument -> extractDocx
    -> buildCanonicalAnalysisDocument -> executeVerifyRun ->
    persistence has not been exercised in a live session with a
    real uploaded DOCX.
    PHASE 9 work item.

  GAP 2 - Paragraph-level similarity is NOT surfaced in the public
    API.
    evaluateParagraphMatch computes paragraph evidence and
    analyzeDocumentEvidence returns it in aggregation.paragraphFlags.
    But executeSimilarityAnalysis narrows its return type to
    SimilarityAnalysisResult, which omits aggregation. Consumers
    needing paragraph-level data must use executeVerifyRun.
    PHASE 10 work item.

  GAP 3 - The scoring engine runs client-side.
    GradifiVerifyDemoPage.tsx calls
    verifyCoreService.executeVerifyRun() in the browser. The server
    validates hashes but does not recompute verification. Receipts
    are therefore client-authored claims. This must be resolved
    before institutional trust can be claimed.
    PHASE 11 work item.
